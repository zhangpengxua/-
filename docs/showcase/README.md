## 素材使用说明

- `01`～`03` 为项目内置圆锥交互示例；`04` 为实际题目输入界面。
- `05`～`15`、`18`～`20` 使用本次人为准备的数学题和追问，通过项目配置的模型实际生成解答、分析、训练和反馈。**这些是功能演示数据，不是真实学生的学习档案或成效统计。**
- 演示训练第一题正确作答；第二题特意漏乘内层导数，展示“部分正确”和具体错误反馈；第三题使用提示后作答，展示辅助练习与独立作答分开统计。
- `16` 是百度 OCR 的实际识别结果，包含字母、函数括号识别偏差；`17` 展示在确认区域人工校正后的文本。它证明可编辑确认流程，不代表 OCR 完全准确。此次未继续提交该图片题进行多模态求解。
- `OCR演示题目.png` 为本次制作的测试输入，不是项目界面截图。
- `index.html` 是可双击打开的离线素材目录，可按文件编号寻找原图，点击查看完整 PNG。
- 截图适合铺满 16:9 幻灯片，或者保留右侧约三分之一放说明。文字较密的分析图建议单独一页，不要缩成四宫格。
- 所有图均为原始页面截图，无额外美化、删改数据或合成。报告中的文字、数学结论及训练题由模型生成，正式答辩时仍应人工检查。

## 通用介绍文案

### 简短介绍

交互学习是一款结合大模型解题、数学可视化和专项训练的学习助手。它把分步推理与二维、三维图形放在同一工作台，并根据历史题目及追问生成有来源依据的复习建议，让学习者通过针对性练习进一步验证理解。

### 详细介绍

本项目围绕数学学习中的“看懂题意、理解过程、发现问题、巩固知识”四个环节展开。用户可以输入文字或上传题目图片，经识别确认后获取分步解答；系统将模型生成的结构化数据转化为公式、二维曲线及可交互三维场景，支持在观察与追问中理解推理。

在复习环节，用户可选择历史题目，查看知识点分析、疑似困难与原始证据，再设置题量和难度生成专项练习。提交答案后，系统提供评分与具体反馈，区分首次独立作答和提示辅助练习，并允许利用训练记录更新分析。由此形成从解题到训练反馈的连续学习流程。

### 展示亮点

- 图文结合：公式、解题步骤与图形在同一工作台呈现。
- 参数探索：通过调节参数观察空间关系和数量变化。
- 来源可查：复习建议与原题、追问证据关联。
- 定向练习：围绕目标知识点生成多题型训练。
- 反馈具体：指出计算或推理中遗漏的环节。
- 统计有区分：提示辅助不计入独立作答成绩。

## 展示时应避免的表述

不要宣称“已经证明能提高成绩”“批改百分之百准确”“适用于全部学科”“历史数据永久保存”或“完成了多用户安全隔离”。这些没有被本次截图和测试证明。

当前数学解答仍可能出现措辞不严谨，例如模型对函数图形特征的解释；截图说明功能存在，不替代对数学内容的人工审校。知识点分析中的“未全对”包含“部分正确”，两者不是互斥数量；整组结果先展示全部首次作答，再单独列独立统计。
